# Portfolio Website

A modern, responsive developer portfolio built to showcase my projects, technical skills, and experience in web development. Designed with a focus on clean UI, smooth animations, and an engaging user experience.

## Live Demo

[View Portfolio](https://rameezik.github.io/Portfolio/)

## Tech Stack

- **HTML5** — Website structure and semantic markup
- **CSS3** — Custom styling and responsive layouts
- **JavaScript** — Interactive functionality and dynamic behavior
- **React** — Component-based UI development
- **Tailwind CSS** — Utility-first styling and responsive design
- **Lucide React** — Clean and consistent icons
- **Animation Libraries** — Smooth transitions, scroll effects, and interactive animations

## Features

- Modern and responsive design
- Smooth animations and transitions
- Interactive UI elements
- Clean and reusable components
- Responsive layouts for different screen sizes
- Dedicated sections for projects, skills, and contact information

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rameezik/Portfolio.git
```

Navigate to the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

*Note: These commands apply if the project uses a React-based setup with a configured `package.json`.*
